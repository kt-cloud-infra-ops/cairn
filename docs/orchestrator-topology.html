핵심 정확성 노트

  • state.json vs triage.json: triage.json(orchestrator GATE 0, guard-orchestrator-entry) ≠ state.json(dev phase, guard-charter) — 독립 가드.
  • guard-charter Phase×Level: state 없음·INIT·PLAN+Standard/Full → exit 2 / PLAN+Lite·IMPL·DONE → 통과.
  • guard-git-commit: staged 런타임코드(.java/.js/.sql/.sh/hooks·*.sh/skills/*/scripts/*/settings.json)만 review-evidence 요구 → 없음/stale/non-pass exit 2. 문서·md 면제.
  • Lite: 산출물·승인 면제이나 GATE 0(state/triage)·GATE 2→3(빌드+테스트)는 적용.
  • guard-service-orchestration.sh [미확인]: service-ops SKILL 언급, hooks/ 부재. 실제 차단은 guard-skill-enforce/guard-orchestrator-entry.
