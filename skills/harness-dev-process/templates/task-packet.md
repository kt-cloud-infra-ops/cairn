# Task Packet

> 개별 구현 태스크의 실행 단위. PRD/Architecture에서 분해된 하나의 작업.
> 에이전트가 이 파일을 읽으면 바로 작업을 시작할 수 있어야 한다.

## 태스크 정보

| 항목 | 내용 |
|------|------|
| Jira 티켓 | [${JIRA_PROJECT_KEY}-XXX] |
| PRD 참조 | [feature-prd.md#FR-N] |
| Architecture 참조 | [feature-architecture.md#섹션] |
| 담당 에이전트/역할 | [backend / frontend / dba / ...] |
| 상태 | `pending` / `in_progress` / `blocked` / `review` / `done` |

## Charter

```
CHARTER_CHECK:
  Goal: [이 태스크가 완료하면 무엇이 달라지는가]
  Context:
    - [수정 대상 파일 1]
    - [수정 대상 파일 2]
    - [참조해야 할 DDL/API 스펙]
  Constraints:
    - [제약 1]
    - [제약 2]
    - [제약 3]
  Done When:
    - [테스트 가능한 완료 기준 1]
    - [테스트 가능한 완료 기준 2]
```

## 입력 (이 태스크를 시작하기 위해 필요한 것)

| 입력 | 위치 | 상태 |
|------|------|------|
| [DDL 스크립트] | [경로] | 확인됨 / [TBD] |
| [API 스펙] | [경로] | 확인됨 / [TBD] |
| [이전 태스크 산출물] | [경로] | 완료됨 / 대기 중 |

| 출력 | 위치 | 검증 방법 |
|------|------|----------|

## 검증 체크리스트

- [ ] 빌드 성공
- [ ] 단위 테스트 통과 (성공 1 + 실패 1 이상)
- [ ] Done When 기준 모두 충족
- [ ] 영향받는 기존 테스트 통과
- [ ] 코드 리뷰 항목 없음 (CRITICAL/HIGH)
