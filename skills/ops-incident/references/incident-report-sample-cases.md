- **영향 범위**: ES0002 채널 한정 (다른 Zabbix/Zenius/o11y 채널 정상)
- **VOC**: 0건

### 3.4 장애 내용 / 원인 / 조치 (요약)

- **장애 내용**: ZabbixEventWorker → `x01_if_event_data` COPY 적재 분당 1회 실패 (BS999), if_idx 미갱신으로 무한 재시도
- **장애 원인**: `ResultSetUtils.convertResultToCSV`가 백슬래시 escape 미처리 + `COPY ... ESCAPE '\'` 옵션 모순. 깨진 row(eventid=713802965)의 본문 끝이 `\` (백슬래시)로 끝나 quoted field 종료 실패 → 다음 row까지 흡수 → unterminated CSV quoted field
- **장애 조치 (임시 회피)**: 박부장님이 Zabbix DB에서 깨진 row 직접 삭제. 17:04 이경수님이 어플리케이션/LOG type 46677 추가 정리
